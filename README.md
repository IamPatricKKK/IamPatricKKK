## About

Full-stack developer at **[ABC Digital](https://github.com/abc-software-solutions-company)** (ABC Software Solutions), shipping client and internal products from the database to the UI and deploying them myself.

- Build **Turborepo / pnpm monorepos** with a NestJS API, Next.js website, React admin portal and React Native app sharing typed packages.
- Comfortable with auth flows end-to-end: JWT access / refresh tokens for web and mobile, OTP password reset, RBAC, Microsoft SSO.
- Own the delivery path: Docker images, GitHub Actions CI/CD to staging and production, VPS, GCP Cloud Build, Vercel.
- Use AI-assisted workflows (Claude Code, spec-driven plans) daily and build automation tools for the team.

> Most of my professional work lives in **private** organization repositories, so the contribution graph shows more than the repo list.
